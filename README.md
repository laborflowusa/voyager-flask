# Voyager-X - AI Travel Deals Platform

A fast, SEO-optimized travel deals website built with Flask, Supabase, and modern HTML/CSS.

## Features

- 99/100 PageSpeed score
- 100/100 SEO score
- Affiliate integration (Amazon, Klook, GetYourGuide)
- AI chat deal finder
- Supabase database for dynamic links
- Fully responsive design

## Tech Stack

- Backend: Flask (Python)
- Database: Supabase (PostgreSQL)
- Frontend: HTML/CSS/JavaScript
- Deployment: Render
